# benchtop

Small projects, built and tested on a bench. Each one is self-contained, runs from a cold clone, and takes about a day to build.

## Layout

One directory per project. Each carries its own `README.md` saying what it builds and how to run it. Nothing at the root is shared, so a directory can be read, run and understood without the others.

```
benchtop/
  <project>/
    README.md      what it builds, how to run it
    ...
```
